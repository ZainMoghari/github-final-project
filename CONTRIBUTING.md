

# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions are welcome.

We welcome:
- Bug reports
- Bug fixes
- Documentation improvements
- Enhancements
- New features
- Ideas and suggestions

## How to Contribute

1. Fork the repository to your GitHub account.
2. Clone the forked repository to your local computer.
3. Create a new branch for your changes.
4. Make the necessary changes or improvements.
5. Test your changes to ensure they work correctly.
6. Stage and commit your changes.
7. Push your changes to your GitHub repository.
8. Create a Pull Request to propose your changes.

## Reporting Bugs

If you find a bug, please open an issue on GitHub.

Describe the problem clearly and provide steps to reproduce it.

## Suggesting Enhancements

We welcome new ideas and improvements.

You can suggest enhancements by opening a GitHub issue and explaining your suggestion.

## Code of Conduct

All contributors must follow the project's Code of Conduct.

Please communicate respectfully with other contributors.

## Thank You

Thank you for helping improve the Simple Interest Calculator project!
